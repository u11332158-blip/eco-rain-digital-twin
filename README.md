Eco-Rain｜壓電撞擊響應與降雨情境模擬
以 PVDF 壓電元件的乾態撞擊量測為起點，結合實測波形、隨機雨滴生成與簡化機電模型，探索不同輸入及表面條件下的響應。
本專案記錄從實驗、第一版網站，到賽後重新檢查與模型修正的研究過程。網站提供可調整參數的介面，讓使用者查看資料、比較假設情境並匯出結果。
研究與實驗：蔣程諺｜目前程式：Eco-Rain 4.1 單檔版
AI 分工與研究狀態
**Model 2 的模型建構與程式實作由 AI 工具完成。**我提供原始資料、既有程式及實驗條件，提出修正需求，並整理研究歷程與證據限制。
六份內建示波器紀錄皆為乾態單次機械撞擊。Model 2 尚未以乾濕實測校正；網站目前用於資料展示與假設情境探索，尚不能預測自然環境下的實際發電量。

一、研究起點與修正歷程
1. 從雨滴發電構想開始
觀察水滴撞擊葉片產生振動後，我開始思考能否利用 PVDF 壓電元件將撞擊轉換為電訊號。在指導老師的指導下，我獨立進行裝置建置、量測與資料整理，並參與研究發表。
實驗使用 Arduino 控制電磁致動裝置進行機械撞擊，最初先測試乾燥狀態的響應。此裝置用於探索撞擊現象，機械撞擊與真實雨滴之間的等效關係仍需另外驗證。
2. 建立第一版模擬網站
第一版將隨機雨滴生成、簡化振動計算與水膜假設整合至網站，讓研究構想能透過參數設定及圖表呈現。其中，水膜影響主要由預設的阻尼與衰減係數描述，電壓換算及累積輸出也使用了簡化設定。
3. 新加坡比賽後重新檢查
回顧評審提問並重新整理程式與紀錄後，我開始區分量測結果、模型假設及尚待驗證的推論，主要釐清三個問題：
- **水膜參數缺少實測校正：**模擬中的輸出下降比例，不能直接當作裝置的發電損失。
- **電壓指標不等於電能：**累積電壓幅值、電壓平方積分與電阻耗能，必須分別定義。
- **改變撞擊頻率可能同時改變輸入：**行程、力道及響應重疊都可能影響量測，不能僅憑輸出大小認定最佳發電頻率。
4. 新版的方向
新版保留實測資料與隨機雨滴生成，重新整理指標，另加入由 AI 完成的 Model 2。各分頁分別說明資料來源、假設條件及結果用途，並提供 CSV 與設定匯出功能。

四、模型如何運作
1. 實測響應疊加
以選取的乾態電壓波形作為單次響應，依撞擊時間與相對振幅疊加：
\[
V(t)=\sum_i a_i h(t-t_i)
\]
其中，$h$ 是擷取後的參考波形、$t_i$ 是事件時間、$a_i$ 是相對振幅。新撞擊發生時，前一次尚未結束的響應仍會保留。
這個方法假設響應形狀穩定且可以線性疊加。改變固定方式、撞擊方式或負載後，需要對應的量測資料；本模型也沒有自動描述高頻下致動器行程與力道的變化。
2. 隨機雨滴生成
隨機雨滴功能仍然保留。新版採用 0.5–6 mm 的截斷 Marshall–Palmer 型分布，以落速加權抽取抵達表面的雨滴，再依雨強、受雨面積及平均雨滴體積設定 Poisson 事件數量，並生成到達時間。
此方法讓期望雨量與設定相符；每次抽樣的實際總雨量仍可能有差異。它不是保留固定截距參數 N₀ 的原始 Marshall–Palmer 模型。
相同參數及隨機種子可重現同一組雨滴事件。固定雨強表示平均降雨強度固定，並不表示每顆雨滴都一樣大。
降雨響應預設以正規化波形及相對撞擊動量計算，不是伏特或發電量。即使另外提供參考衝量進行換算，也仍需驗證雨滴與機械撞擊的傳力差異。
3. Model 1：舊假設情境
依雨強及預設速率更新濕潤程度，再透過阻尼與衰減設定計算比較指標。此分頁用來檢查舊假設對輸出的影響，未建立水量守恆、完整水膜運動或機電耦合模型。
4. Model 2：固定水膜的單次撞擊模型
此部分的模型建構與程式實作由 AI 完成。
乾、濕兩種情境使用相同的雨滴尺寸與撞擊速度，透過簡化的機電耦合模型計算響應。主要改變包括：
- **水膜附加有效質量：**由水膜厚度、覆蓋面積及質量參與係數估算；額外阻尼另行設定。
- **機電耦合：**納入機械運動、電容、耦合參數及負載電阻，取代第一版單純以比例係數換算電壓的方式。
- **撞擊假設：**乾、濕情境均假設雨滴撞後附著，以動量設定初始運動；濕態可另外設定動量傳遞倍率。
- **數值計算：**以矩陣指數推進線性常係數系統，計算電阻耗能、機械耗散、剩餘儲能與能量平衡誤差。
參數目前均為可調整的假設值，尚未以本專案乾濕實測校正。模型採單一集中自由度、小振幅、固定水膜、線性阻尼與純電阻負載，未描述水波、飛濺、排水及水膜累積。
隨機降雨分頁與 Model 2 目前分開運作，尚未串成水膜隨降雨持續變化的完整模型。「模型優化」指計算方式與結果定義的改善，不代表裝置發電效能已提升。
五、輸出指標的意義
指標	意義	是否為電能
峰值電壓	波形中的最大或最小電壓	否
累積電壓幅值	依取樣及計算定義形成的訊號比較指標	否
電壓平方積分	電壓平方隨時間積分，單位為 V²·s	否
雨滴入射動能	由雨滴質量與速度計算的 ½mu²	是機械能，不是輸出電能
電阻耗能	已知電阻兩端電壓的 V²/R 時間積分	是；仍須區分實測與模型計算


\[
E_R=\int \frac{V_R^2(t)}{R_L}\,dt
\]
只有確認波形量自已知純電阻兩端時，才可用該負載值計算實測電阻耗能。不能任意填入電阻，就把原有電壓波形當作該負載下的輸出。
Model 2 顯示的是模型電阻在計算期間的耗能，未包含整流、儲能與其他電路損失。數值能量平衡是計算檢查，不等於模型已符合真實裝置。

七、在本機執行
以下步驟適用於 4.1 完整單檔版。將完整程式儲存為 app.py，在該檔案所在資料夾執行：
python -m pip install streamlit numpy pandas scipy plotly
python -m streamlit run app.py
若儲存庫已有 requirements.txt，可依該檔案安裝相依套件：
python -m pip install -r requirements.txt
python -m streamlit run app.py
單檔版已包含計算函數與六份原始 CSV，不需要另外安裝 physics_core 套件。如果仍出現 ModuleNotFoundError: No module named 'physics_core'，請確認執行的是完整單檔版，而非仍引用外部模組的舊檔案。
上述指令依提供的單檔程式與相依套件整理；執行環境與套件版本仍需在實際部署環境確認。
八、建議操作順序與結果匯出
1. 在「實測資料」查看原始波形與擷取後的響應，確認資料來源及時間定義。
2. 在「連續撞擊」調整頻率，觀察響應重疊；不要將頻率提高直接解讀為實際撞擊力保持不變。
3. 在「降雨模擬」設定雨勢、面積及種子，生成雨滴事件，查看相對乾態響應。
4. 在「Model 1」檢查舊假設的影響，再於「Model 2」比較固定條件下的乾濕情境。
5. 匯出需要的 CSV，並保存相關設定，讓圖表能追溯到輸入條件。
可下載的內容包括擷取波形、連續撞擊結果、雨滴事件、降雨響應片段、Model 1 指標與 Model 2 結果。「模型與文獻」提供主要資料與降雨設定 JSON；Model 2 的參數需另外記錄，不能假設主要設定 JSON 已包含全部分頁設定。
氣象 CSV 支援 Time,Rain、time_h,rain_mm_h 或 time_s,rain_mm_h。以秒為例：
time_s,rain_mm_h
0,20
60,50
120,0
此例表示 0–60 秒為 20 mm/h、60–120 秒為 50 mm/h；最後一列時間為結束邊界，不另建立新的區間。它是輸入格式範例，不代表真實氣象觀測。
九、目前結論與下一步
目前可以呈現乾態撞擊的電壓紀錄，並在明確假設下探索響應疊加、雨滴事件及固定水膜的模型趨勢。
目前尚未確認：
- 水膜造成的實際發電損失比例。
- 100 Hz 為裝置共振頻率，或 33.3 Hz 為最佳發電頻率。
- 由六份電壓紀錄直接得到唯一的機械阻尼比。
- 自然降雨中的實際發電量，或排水設計帶來的實際增益。
後續規劃：
- [ ] 固定撞擊條件與量測電路，確認乾態響應的重複性。
- [ ] 加入已知水量，完成乾濕對照與參數校正。
- [ ] 以未參與校正的資料檢查模型預測能力。
- [ ] 以真實水滴及已知負載進行量測，檢查機械撞擊與雨滴撞擊的差異。
- [ ] 驗證整流與儲能後的可用能量，再評估應用。
- [ ] 在取得足夠資料後，評估如何串接降雨事件、水量變化與機電模型。
